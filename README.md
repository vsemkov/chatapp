# Чат-приложение (Frontend)

Веб-приложение для обмена сообщениями в реальном времени с поддержкой групповых чатов.

## Технологический стек

### Основные технологии
- **Vue 3** — прогрессивный JavaScript-фреймворк
- **TypeScript** — типизированный JavaScript
- **Pinia** — управление состоянием приложения
- **Vue Router** — маршрутизация
- **Socket.IO Client** — WebSocket-соединение для реального времени
- **Vite** — быстрый сборщик и сервер разработки
- **Tailwind CSS** — утилитарный CSS-фреймворк

### Тестирование
- **Vitest** — юнит-тестирование
- **Vue Test Utils** — тестирование Vue-компонентов
- **JSDOM** — эмуляция DOM-окружения

## Установка и запуск

### Требования
- Node.js v18 или выше
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Настройка окружения

Создайте файл `.env` в корне проекта:

```env
VITE_IO_URL=http://localhost:3001  # URL Socket.IO сервера
```

### Режимы запуска

#### Режим разработки
```bash
npm run dev
```
Сервер будет доступен по адресу: `http://localhost:5173`

#### Сборка для продакшена
```bash
npm run build
```

#### Предпросмотр собранного приложения
```bash
npm run preview
```

#### Запуск тестов
```bash
npm run test
```

#### Запуск тестов с UI
```bash
npm run test:ui
```

## Основные функции

### Аутентификация
- Вход в систему по логину/паролю
- JWT-токен хранится в Pinia-хранилище
- Защита маршрутов через Vue Router

### Управление чатами
- Список всех доступных чатов
- Создание новых чатов
- Выбор активного чата
- Отображение участников чата
- Приглашение новых участников

### Обмен сообщениями
- Отправка сообщений в реальном времени
- Автоматическое получение новых сообщений через Socket.IO
- Обновление последнего сообщения в списке чатов
- Поддержка текстовых сообщений

### Статусы пользователей
- Онлайн/офлайн статус участников
- Обновление статуса в реальном времени

### UI/UX
- Адаптивный дизайн
- Интуитивно понятный интерфейс
- Аватарки пользователей
- Индикация печати (готовится)

## 🔌 API Интеграция

Приложение взаимодействует с бэкендом через REST API и WebSocket:

### REST API эндпоинты
- `POST /auth/login` — аутентификация
- `GET /chats` — список чатов
- `GET /messages/:chatId` — история сообщений
- `POST /messages` — отправка сообщения

### WebSocket события
- `connect` — установка соединения
- `message` — новое сообщение
- `invite` — приглашение в чат
- `typing` — индикация печати
- `status` — обновление статуса
- `read` — отметка о прочтении
